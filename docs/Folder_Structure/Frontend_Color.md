# CHURCH PLATFORM UI COLOR SPECIFICATION

## Design System Overview

The platform uses a modern futuristic glassmorphism aesthetic with dual theme support:

* Dark Mode → cinematic futuristic spiritual experience
* Light Mode → elegant soft glassmorphism experience

The design must always feel:

* premium
* immersive
* modern
* spiritual
* minimal
* emotionally calming

The UI should maintain strong visual consistency across:

* sermons
* blogs
* events
* prayer modules
* notifications
* dashboards
* profile pages

---

# PRIMARY DESIGN STYLE

* Glassmorphism
* Soft gradients
* Rounded corners
* Neon ambient glow
* Frosted glass effects
* Cinematic lighting
* Minimal modern UI
* Premium SaaS dashboard aesthetic

# COMPONENT DESIGN RULES

## Cards

* Rounded corners
* Glassmorphism effect
* Soft border glow
* Slight hover elevation

## Buttons

* Gradient backgrounds
* Soft glow
* Rounded-xl
* Smooth hover transitions

## Navbar

* Transparent or frosted glass
* Blur background
* Minimal border

## Sidebar

* Semi-transparent
* Purple active state
* Soft hover lighting

---

# DESIGN RULES

* Never use harsh pure white backgrounds
* Never use flat material design appearance
* Always maintain glassmorphism aesthetic
* Maintain purple-centered visual identity
* Use soft ambient lighting
* Keep rounded corners across the UI
* Use cinematic spacing and depth
* Maintain premium SaaS-style layout

---

# AI DESIGN RULES

When generating UI screens:

* Maintain consistent futuristic glassmorphism aesthetic
* Use dark purple futuristic theme in dark mode
* Use soft lavender frosted aesthetic in light mode
* Maintain premium spiritual/community platform appearance
* Use glow effects subtly
* Avoid cluttered UI
* Keep layouts spacious and immersive
* Maintain visual consistency across all pages
* Preserve same brand identity in both modes
